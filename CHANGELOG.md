## [Unreleased]

### Added

- Added the Protocol Buffers and gRPC definitions previously provided by the
  `protobuf` and `grpc` directories of `github.com/dogmatiq/enginekit`, along
  with their Go helpers. The envelope packers, the `uuidpb.Map` and
  `uuidpb.Set` collection types, and the `configpb` and `configgrpc` packages
  remain in `enginekit`.
- Added the `CommandExecutorAPI` gRPC service to `messaginggrpc`, along with the
  `UnrecognizedApplication`, `UnrecognizedCommandType`, `UnrecognizedEventType`,
  `MalformedMessage` and `InvalidMessage` error details and their Go
  constructors.
- Added the `@dogmatiq/protobuf` npm package, containing code generated by
  `protoc-gen-es`.
- Added `generateUUID()`, `deriveUUID()`, `parseUUID()`, `uuidToString()`,
  `uuidEquals()` and `validateUUID()` to the TypeScript `uuidpb` package.
- Added `validateIdentity()` and `identityToString()` to the TypeScript
  `identitypb` package.
- Added `expandMultiEnvelope()`, `asMultiEnvelope()`, `tryAppendEnvelope()`,
  `validateEnvelope()`, `validateMultiEnvelope()`, `getExtension()`,
  `setExtension()`, `getBaggage()` and `setBaggage()` to the TypeScript
  `envelopepb` package.

### Changed

- **[BC]** Moved `UUID`, `Identity`, `Envelope`, `EventStreamPosition` and
  related types from the `dogma.protobuf` package to `dogma.protobuf.v1`. This
  changes the type URLs of these types when they are packed in a
  `google.protobuf.Any`.
